## 📘 Short Notes: **Type Conversion in Python**

### 1️⃣ What is Type Conversion?

Type conversion means converting data from **one data type to another**.
Python supports **two kinds** of type conversion:

---

## 2️⃣ Implicit Type Conversion (Automatic)

* Done **automatically by Python**
* Happens to **avoid data loss**
* Common with numeric types

### 🔹 Rules

* `bool → int → float`
* Integer + Float → Float
* Boolean acts like numbers (`True = 1`, `False = 0`)

### 🔹 Examples

```python
a = 10      # int
b = 1.5     # float
c = a + b  # int → float
print(c)   # 11.5
```

```python
x = True
y = 10
print(x + y)   # 11
```

✔ No syntax needed
✔ Happens safely

---

## 3️⃣ Explicit Type Conversion (Manual)

* Programmer **explicitly converts**
* Uses **constructor functions**

### 🔹 Common Conversion Functions

| Function  | Converts To |
| --------- | ----------- |
| `int()`   | Integer     |
| `float()` | Float       |
| `str()`   | String      |
| `list()`  | List        |
| `tuple()` | Tuple       |
| `set()`   | Set         |

---

### 🔹 String → Number

```python
s = "135"
i = int(s)
f = float(s)

print(i)  # 135
print(f)  # 135.0
```

⚠ Invalid strings cause errors:

```python
int("abc")  # ❌ ValueError
```

---

## 4️⃣ String ↔ Containers

### String → List / Tuple / Set

```python
s = "GEEKS"

print(list(s))   # ['G','E','E','K','S']
print(tuple(s))  # ('G','E','E','K','S')
print(set(s))    # {'G','E','K','S'} (distinct, unordered)
```

📌 Set removes duplicates and order is unpredictable

---

### Container → String

```python
lst = [10, 20, 30]
print(str(lst))  # "[10, 20, 30]"
```

✔ This is just a **string representation**

---

## 5️⃣ Number → String & String Concatenation

```python
a = 10
b = 11

print(str(a) + str(b))  # "1011"
```

📌 `+` with strings means **concatenation**, not addition

---

## 6️⃣ Tuple / Set → List

### Tuple → List (to modify data)

```python
t = (10, 20, 30)
lst = list(t)
```

### Set → List (unordered → ordered)

```python
s = {30, 10, 20}
lst = list(s)
```

⚠ Order may change when converting from set

---

## 7️⃣ Integer → Binary / Octal / Hexadecimal

| Function | Base | Prefix |
| -------- | ---- | ------ |
| `bin()`  | 2    | `0b`   |
| `oct()`  | 8    | `0o`   |
| `hex()`  | 16   | `0x`   |

```python
n = 20
print(bin(n))  # 0b10100
print(oct(n))  # 0o24
print(hex(n))  # 0x14
```

---

## 8️⃣ String (Base-N) → Decimal Integer

Use `int(value, base)`

```python
print(int("1001", 2))   # 9
print(int("12", 8))     # 10
print(int("A1", 16))    # 161
```

### 🔹 Valid Characters

* Base 2 → `0–1`
* Base 8 → `0–7`
* Base 16 → `0–9`, `A–F`

---

## 🧠 Key Takeaways (Exam / Viva Ready)

* Python converts **upwards** automatically (no data loss)
* `get()` vs `[]` equivalent exists in dicts, **not in type conversion**
* Sets remove duplicates during conversion
* String concatenation ≠ numeric addition
* Base conversion needs **explicit base**

# 🧪 ONE Full Coding Problem (Type Conversion)

### 📝 Problem Statement

You are given:

* A tuple of numbers
* A string representing a number
* An integer

Write a program to:

1. Convert the tuple into a list and add a new number
2. Convert the string into an integer and add it to the integer
3. Convert the final integer result into binary, octal, and hexadecimal
4. Convert the list into a set and then into a string

---

### 💻 Coding Problem

```python
data_tuple = (10, 20, 30)
num_str = "40"
num = 5

# Step 1: Tuple → List and modify
data_list = list(data_tuple)
data_list.append(50)

# Step 2: String → Int and arithmetic
total = int(num_str) + num

# Step 3: Number base conversions
binary = bin(total)
octal = oct(total)
hexa = hex(total)

# Step 4: List → Set → String
unique_data = set(data_list)
final_str = str(unique_data)

print(data_list)
print(total)
print(binary, octal, hexa)
print(final_str)
```

---

✔ Tuple → List
✔ String → Int
✔ Arithmetic after conversion
✔ Base conversions
✔ List → Set (distinct)
✔ Set → String
