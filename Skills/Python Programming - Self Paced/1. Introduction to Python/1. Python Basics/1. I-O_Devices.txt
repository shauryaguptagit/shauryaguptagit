# 🧠 Hardware Basics for Programmers (Short Notes)

## 1️⃣ Input & Output Devices

### What are Input Devices?

Devices used to **give data/instructions to the computer**.

**Examples**

* Keyboard
* Mouse / Touchpad
* Scanner
* Microphone (Mic)

👉 Any action where **user provides data = Input**

---

### What are Output Devices?

Devices through which **computer gives results/output**.

**Examples**

* Monitor / Display
* Speakers
* Earphones
* Printer

👉 Any action where **computer shows or plays result = Output**

---

### Devices that are BOTH Input & Output

* **Printer–Scanner combo**

  * Printer → Output (hard copy)
  * Scanner → Input (soft copy)

---

## 2️⃣ CPU (Central Processing Unit)

### What is CPU?

* The **brain of the computer**
* Performs **all computations and execution**

### Key Points

* Executes instructions **instruction by instruction**
* Gets heated due to heavy computation
* Requires a **cooling fan**

📌 **Viva Line**

> CPU performs calculations and executes instructions.

---

## 3️⃣ Memory Types (Very Important)

### Why Do We Need Memory?

* To **store data and programs**
* CPU **cannot work without memory**

---

### 🔹 1. Cache Memory

* Present **inside CPU chip**
* **Fastest access**
* **Very costly**
* **Very small size**
* Stores **frequently used data**

📌 Example: Variables accessed repeatedly

---

### 🔹 2. Main Memory (RAM)

* Also called **Random Access Memory**
* Programs are **loaded & executed here**
* **Temporary storage**
* Data is lost when power is OFF (volatile)

📌 CPU **directly communicates only with RAM**

---

### 🔹 3. Secondary Memory (Hard Disk)

* **Permanent storage**
* Stores OS, software, files
* **High capacity**
* **Low cost**
* **Slow access**

**Examples**

* Hard Disk (internal/external)
* USB
* CD / DVD

---

### 🔁 Volatile vs Non-Volatile

| Memory    | Volatility   |
| --------- | ------------ |
| Cache     | Volatile     |
| RAM       | Volatile     |
| Hard Disk | Non-Volatile |

---

## 4️⃣ How a Program Runs (Execution Flow)

1. Program is stored in **Hard Disk**
2. On execution (double click):

   * Program is **copied to RAM**
3. CPU:

   * Fetches instructions from **RAM**
   * Executes them step-by-step

📌 **Important Rule**

> CPU takes instructions ONLY from RAM.

---

## 5️⃣ Role of Operating System (OS)

### What is an Operating System?

* A **software**
* Takes control when system boots
* Acts as **manager of the system**

### Responsibilities

* Brings programs from **Hard Disk → RAM**
* Manages CPU time (fair sharing)
* Manages memory
* Manages input/output devices

**Examples**

* Windows (7, 10, etc.)
* Linux (Ubuntu, CentOS)
* Unix
* macOS

📌 **Viva Line**

> Operating System is the interface between hardware and software.

---

## 6️⃣ Logical Organization of Computer

```
CPU
 ├── Cache
 └── RAM
        ↓
     Hard Disk
```

* CPU directly accesses **Cache & RAM**
* Cache is **inside CPU**

---

## 7️⃣ Why 3 Types of Memory?

### Desirable Memory Features

1. **Low access time**
2. **Low cost**
3. **High capacity**

❌ No single memory satisfies all three

---

### Comparison Table

| Memory    | Speed     | Cost      | Capacity  |
| --------- | --------- | --------- | --------- |
| Cache     | Very Fast | Very High | Very Low  |
| RAM       | Medium    | Medium    | Medium    |
| Hard Disk | Slow      | Low       | Very High |

---

## 8️⃣ Shopkeeper Analogy (Easy to Remember)

| Computer  | Shop                            |
| --------- | ------------------------------- |
| Cache     | Front Counter (most used items) |
| RAM       | Shop Area                       |
| Hard Disk | Store Room                      |

* Frequently used data → Cache
* Less frequent → RAM
* Rarely used → Hard Disk
* OS acts like the **helper bringing items**

---

## 🎯 One-Page Summary (Exam Gold)

* Input devices → give data
* Output devices → show results
* CPU → executes instructions
* Cache → fastest, smallest
* RAM → execution memory (volatile)
* Hard Disk → permanent storage
* OS → manages everything
* Program must be in **RAM to execute**
