## 🧠 About Me

I'm a Data Analyst who spent the last 5 months at **Koraa.ai** building a 19-store, 4-channel order reconciliation system — matching POS data against Zomato, Swiggy, and Magicpin settlement files across **~180K records** at **99.6% match accuracy**.

The work requires SQL that handles what naïve queries miss — dual-row DSR formats, sign-flipped reversal rows, cross-channel grain mismatches — and surfaces discrepancies finance teams would otherwise never catch.

Navigating toward **Data Engineering** from the analyst seat.
